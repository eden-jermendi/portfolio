# Eden Jermendi Portfolio

A production ready portfolio built with Next.js, TypeScript, and React, designed to showcase selected software engineering projects, technical case studies, and ongoing learning.
The site focuses on clean architecture, accessibility, performance, and maintainable frontend engineering while providing a central place to explore my work, experience, and development journey.

## Preview

**Live Deployment:** Hosted on [Vercel.](https://edenjermendi.com/)

## Tech Stack

### Core
- Next.js 15 (App Router)
- React 19
- TypeScript
- Styled Components

### Frontend
- HTML5 and CSS3
- Responsive Design
- CSS Animations

### Tooling
- Turbopack (compiler)
- ESLint
- Prettier
- npm
- Vercel
- Antigravity agent

## Features
- Responsive layout across desktop, tablet, and mobile
- Modern single-page application architecture
- Project showcase with live demos and GitHub repositories
- Technical case studies explaining design decisions and implementation
- Viewable and downloadable CV
- Contact links
- Animated but accessible user interface
- SEO metadata and social sharing support
- Optimised asset loading with Next.js
- Fully typed TypeScript codebase

The portfolio is continuously deployed through Vercel, providing automatic deployments for new commits and pull requests.

## Purpose
Rather than acting as a simple project gallery, this portfolio serves as an engineering project in its own right.

It demonstrates my approach to designing maintainable React applications, organising scalable codebases, building reusable UI components, and documenting technical decisions through accompanying case studies.
As I continue moving further into backend engineering and systems development, the portfolio will evolve alongside that progression.
