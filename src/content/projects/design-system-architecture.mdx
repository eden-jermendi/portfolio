This project serves as the architectural foundation for my personal portfolio. It was built from the ground up on the Next.js App Router with a strict server-first philosophy, deliberately avoiding heavy client-side JavaScript execution and runtime styling libraries.

Key engineering decisions include:
- A custom Markdown/MDX pipeline validated rigorously at build-time using Zod.
- A zero-runtime styling system using CSS Modules and native custom properties.
- A hyper-focus on semantic HTML, native browser behavior, and performance overhead reduction.
